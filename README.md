# Palmares-template-

Web app interactiva premium (frontend puro) para creadores, artistas, nómades digitales y una vertical de barbería/academia.

## Ejecutar local

```bash
python3 -m http.server 8080
```

Abrir: `http://localhost:8080`

## Incluye

- Home cinematográfico con loader, navbar flotante y parallax.
- 9 secciones estratégicas con artículos, checklist y herramientas de descarga (TXT/HTML/PDF).
- Modo claro/oscuro + selector de idioma ES/EN/PT.
- Calendario con reloj en tiempo real y notas por día (localStorage).
- Blog, comentarios y formulario de contacto (persistencia local).
- Panel admin local para lectura de contactos/comentarios.
